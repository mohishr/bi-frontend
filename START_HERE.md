## 🔄 What Happens When You Search

1. **User types query** → Stored in state
2. **User clicks Search** → performSearch() called
3. **API call made** → searchAPI.search() to backend
4. **Results returned** → searchAPI receives JSON
5. **Results displayed** → SearchResults component renders
6. **User clicks result** → handleChatSearchResult() called
7. **File preview opens** → FilePreviewDialog shows file

**All in real-time, no page reload!** ✅
